3. API Hello Cloud

Ứng dụng được xây dựng bằng Node.js và Express, tách phần ứng dụng khỏi tệp khởi động để thuận tiện tái sử dụng.

HTTP Method: GET

Endpoint: /

Port: 3000

Thông điệp: Xin chào từ đám mây!

Dữ liệu trả về: host, platform, cpus, memoryGB, uptimeSec và time.

Kết quả kiểm tra: API trả JSON thành công trên trình duyệt máy tính và điện thoại.

API chạy trong Codespace khi môi trường hoạt động. GitHub Pages chỉ xuất bản trang web tĩnh, không trực tiếp vận hành API Node.js.

4. Năm đặc tính thiết yếu của điện toán đám mây theo NIST

Liên hệ từng đặc tính với thao tác đã thực hiện trong bài thực hành.

01 · ON-DEMAND SELF-SERVICE

Tự phục vụ theo nhu cầu

Sinh viên tự chọn repository, mở Code → Codespaces và tạo môi trường phát triển mà không cần yêu cầu nhân viên quản trị cấp máy hoặc tự cài đặt toàn bộ môi trường trên máy cá nhân.

02 · BROAD NETWORK ACCESS

Truy cập mạng rộng rãi

Môi trường Codespaces được truy cập qua trình duyệt. API cổng 3000 được chuyển sang Public để điện thoại mở URL và nhận dữ liệu JSON, sau đó có thể chuyển lại Private.

03 · RESOURCE POOLING

Gộp tài nguyên

Codespaces cấp tài nguyên tính toán từ hạ tầng đám mây của nhà cung cấp. Sinh viên sử dụng máy ảo có 2 CPU logic và 7.8 GB RAM mà không trực tiếp quản lý máy chủ vật lý.

04 · RAPID ELASTICITY

Co giãn nhanh

Sinh viên có thể khởi chạy hoặc dừng Codespace theo nhu cầu. Đây là trải nghiệm cấp phát và ngừng sử dụng môi trường; bài thực hành chưa thử tăng hoặc giảm cấu hình CPU và RAM.

05 · MEASURED SERVICE

Dịch vụ đo lường được

GitHub Billing Usage ghi nhận mức sử dụng lưu trữ 0.538429 GB-month, Gross amount 0.03769 USD và Billed amount 0 USD sau khi áp dụng included usage discount.

5. Kết luận

Qua bài thực hành, sinh viên đã tạo và sử dụng môi trường phát triển trên GitHub Codespaces, xây dựng API Hello Cloud bằng Node.js và Express, kiểm tra khả năng truy cập API từ thiết bị di động và theo dõi mức sử dụng trên GitHub Billing.

Trải nghiệm cho thấy môi trường đám mây giúp người học sử dụng tài nguyên qua mạng mà không phải trực tiếp quản lý máy chủ vật lý. Một số chỉ số như thời gian khởi tạo ban đầu và Compute/Core-hours chưa được ghi nhận trong lần thực hiện này.
